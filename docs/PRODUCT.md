# 个税规划器 — 产品设计

## 目标用户与痛点
- 中国大陆居民、工资薪金为主要收入的打工人。
- 痛点：累计预扣法 + 五险一金 + 专项附加扣除 + 年终奖/股权激励单独计税，普通人算不清：
  1. 这个月为什么税突然变多（预扣税率跳档）；
  2. 一年到底交多少税、汇算清缴是退还是补；
  3. 年终奖怎么发（单独 / 并入 / 发多少）税最低；
  4. 期权/RSU 什么时候行权税最低；
  5. 中间有 gap、换过工作，怎么算。

## 输入模型（越少越好）
1. **工作时间线**：12 个月的格子，添加「工作段」= 起止月 + 税前月薪（+ 可选公司名）。没被覆盖的月份 = gap。允许重叠（兼职双薪，两家各自预扣）。
2. **每段可选**：
   - 某个月的税后到手 → 反推该段五险一金个人缴纳额（唯一解，二分求解）。
   - 年终奖金额 + 发放月份。
   - 高级：手动填社保基数/公积金基数/比例；「今年首份工作（应届）」减除费用从 1 月累计。
3. **专项附加扣除**（全年适用）：子女教育、继续教育、房贷/租房、赡养老人、婴幼儿、大病医疗、个人养老金、其他。
4. **城市**：决定社保/公积金基数上下限 + 租金档位，仅作默认值。

## 输出
- **总览卡片**：全年税前、五险一金、应纳税所得额、全年应纳税、已预扣、汇算退/补、全年到手、综合税负、边际税率。
- **月度明细**：每月税前 / 五险一金 / 预扣税 / 到手、累计应纳税所得额与所处预扣率档位（可视化“爬楼梯”）。今天以后的月份标为预测。
- **年终奖**：单独 vs 并入对比 + 推荐；如果可与公司协商比例，给出最优“工资:奖金”拆分；陷阱区间提醒。
- **期权/RSU**：上市公司股权激励单独计税（年度税率表，全年合并），对比一次行权 vs 跨 2/3 年分批；非上市备案递延按 20%。
- **减税建议**：按预计节省金额排序的可执行清单（未申报的专项附加、个人养老金、公积金比例、年终奖模式、期权跨年、gap 月退税提醒、汇算清缴时间）。

## 计算口径（2019–2027 有效规则）
- 综合所得年度 7 级超额累进税率表；月度换算表用于年终奖单独计税。
- 预扣预缴：累计预扣法，减除费用 5000 × 本单位任职月数（应届可从 1 月累计），累计专项扣除 + 累计专项附加扣除；本期税额 = 累计应纳税额 − 已预扣，负数取 0。
- 汇算清缴：全年收入 − 60000 − 全年五险一金 − 全年专项附加（含 gap 月）− 个人养老金 − 大病医疗等 → 年度税率表。退/补税 = 应纳 − 已预扣。
- 年终奖单独计税：奖金 ÷ 12 找月度税率 → 奖金 × 税率 − 速算扣除（政策至 2027-12-31）。
- 股权激励（上市公司）：不并入综合所得，全年合并按年度税率表（政策至 2027-12-31）。
